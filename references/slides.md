# スライドのページ型（暫定）

16:9 のスライドの共通の型。2026-10-27 に WealthPark RealEstate Technologies の会社紹介資料（Company Deck）を作り直したときの型を AI が下書きしたもので、**暫定**。承認されるまでルールとして扱わない。

## 判型と余白

- 16:9。HTML で作るときは 1920 × 1080px（幅 10in のスライドに写すと 1px = 1/192in）
- 外周の余白は上下左右とも同じ値にする（例: 96px）。上だけ狭い、左だけ広い、のようにずらさない
- 本文の領域は余白の内側。フッターは下の余白の中に置く

## 書体

- Google スライドで使い回す資料: 和文 Noto Sans JP、欧文 Arial。Google スライドには游ゴシックとヒラギノが無い（游ゴシックを指定しても代わりの書体で表示される）
- PowerPoint だけで使う資料: 游ゴシックでもよい
- 1 つの文の中でも、和文の部分と欧文の部分に別の書体を当てる。PowerPoint と Google スライドは文字の範囲（run）ごとに書体を持つ

## 共通の部品

| 部品 | 位置と見た目 |
|---|---|
| 章ラベル | 左上。事業のアクセント色の短い縦の線と、章の名前（20px、#666666） |
| タイトル | 章ラベルの下。44px、太字、#1A1A1A、1 行 |
| タイトルの下の罫 | 全幅、2px、#EEEEEE |
| フッター | 左下に会社名（16px、#999999）、右下にページ番号（黒の正方形に白の数字） |
| カード | #F5F5F5、角丸 12px。左上に 40 × 4px のアクセント色の線 |
| 数字 | 大きな数字はアクセント色の太字、単位は小さく黒 |
| 箇条書き | 行頭にアクセント色の小さな丸 |
| 列の見出し | 黒 #1A1A1A の帯に白の太字 |

## ページの種類

| 種類 | 型 |
|---|---|
| 表紙 | 黒の地にキービジュアル（画像）。左に白のタイトル、その下にアクセント色の短い線と年月、左上に白版ロゴ |
| 章の扉 | 黒の地。アクセント色の章番号（細字、大きく）、短い線、白の章タイトル、左下に白版ロゴ |
| 本文 | 白の地。共通の部品で組む |
| PR ページ | テンプレートの例外。写真を全面に敷き、暗い部分に白抜きの文字を置く。フッターが写真と重なるなら外してよい |
| 締め | 表紙と同じ黒の地。「Thank you」と白版ロゴ |

## 公開する資料

- コーポレートサイトなどで公開する資料には「Strictly Confidential」などの機密表示を入れない
- 人物の写真や役職は https://wealth-park.com/ja/company/ の掲載に合わせる（顔ぶれが変わるので、このキットには写し取らない）

## 図とグラフ

- グラフの配色は charts.md（Carbon）。円グラフはドーナツにし、凡例は右に表で置く
- 図解の素材（アイコン、挿絵、国旗、地図）と形の段階は graphics.md
- 元の資料に画像で貼られた表や図は、文字と図形で組み直して編集できるようにする
