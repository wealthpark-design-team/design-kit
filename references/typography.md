# タイポグラフィ

Web、スライド、チラシ、動画で共通の決まり。サイズの体系は未定なので、決まっている範囲だけ書く。

## フォントの優先順

| 優先 | 欧文 | 和文 | 備考 |
|---|---|---|---|
| 1 | Helvetica Neue | ヒラギノ角ゴシック（Hiragino Kaku Gothic ProN / Hiragino Sans） | Mac と iOS に標準で入っている |
| 2 | Noto Sans | Noto Sans JP | 1 が無い環境（Windows、Google スライドなど）。セリフ体が必要なときは Noto Serif JP |
| 3 | 游ゴシック | 游ゴシック | 1 も 2 も無い環境（Windows の Office など） |

Web の CSS ではこの順にフォールバックする指定を assets/tokens.css に入れている。

## サイズ

- Web の本文: 16px、行間 1.7〜1.8
- 見出し、キャプション、スライド、チラシ、動画のサイズは未定。用途ごとの事例（表紙、本文ページ、キャプションなど）と一緒に決める。それまでは本文サイズだけを守る

## Web の UI（CSS 変数）

サイズスケール（12 / 14 / 16 / 18 / 22 / 24 / 30 / 40 / 50 / 64 / 72 px）、余白（4〜80px）、角丸（3 / 4 / 12 / 999px）、線幅（1 / 2px）は assets/tokens.css の値を使う。これはコーポレートサイトの実装値で、Web 以外には当てはめない。
