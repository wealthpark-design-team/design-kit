# 図解・挿絵・形・国旗・地図（暫定）

資料の図解やインフォグラフィックを組むときの素材と形の目安。グラフに IBM Carbon のパレットを借りているのと同じく、既成の体系を用途ごとに 1 つずつ借りる。

この文書はすべて**暫定**。2026-10-27 に WealthPark RealEstate Technologies の会社紹介資料で試した結果を AI が下書きしたもので、承認されるまでルールとして扱わない。

| グラフの配色 | IBM Carbon のデータ可視化パレット | Apache-2.0 | 採用済み。charts.md |

アイコンと挿絵は 1 つの制作物の中で体系を混ぜない。Material Symbols のアイコンと Carbon のピクトグラムは、大きさと役割が違う（記号と挿絵）ので同じページに並べてよい。

## 挿絵: Carbon のピクトグラム

- 一覧: https://carbondesignsystem.com/elements/pictograms/library/ 。npm の `@carbon/pictograms` に SVG がある
- 線の細い単色の絵。「契約」「送金」「グローバル」「建物」のような概念を、アイコンより大きく描くときに使う
- 色は黒 #1A1A1A の 1 色。強調したい 1 点だけ事業のアクセント色にする
- 大きさは 64〜160px。同じページの中ではそろえる
- IBM の資料の雰囲気が強く出ることがある。数ページで試してから広げる

## 形・余白・影: Material Design 3 から借りる値

出典: https://m3.material.io/styles/shape と https://m3.material.io/styles/elevation 。

角丸（M3 の形の段階）

| 段階 | 値 | 使いどころ |
|---|---|---|
| none | 0 | 帯、表、全面の写真 |
| extra-small | 4px | 小さな札、チップ |
| small | 8px | 写真、吹き出し、小さなカード |
| medium | 12px | カード、パネル（このキットの --wp-radius-lg と同じ） |
| large | 16px | 大きなパネル |
| extra-large | 28px | 目立たせたい大きな面 |
| full | 高さの半分 | 丸、ピル |

余白は 4 の倍数で取る。スライド（1920 × 1080px）では、外周の余白を上下左右とも同じ値にそろえる（RET の資料は 96px）。

影（M3 の高さ）。Web のカードやボタンで使う。スライドでは影を使わないか、1 段だけにする（PowerPoint と Google スライドは単純な影しか写せない）。

| 段階 | CSS の box-shadow |
|---|---|
| 1 | 0 1px 2px rgba(0,0,0,.3), 0 1px 3px 1px rgba(0,0,0,.15) |
| 2 | 0 1px 2px rgba(0,0,0,.3), 0 2px 6px 2px rgba(0,0,0,.15) |
| 3 | 0 1px 3px rgba(0,0,0,.3), 0 4px 8px 3px rgba(0,0,0,.15) |
| 4 | 0 2px 3px rgba(0,0,0,.3), 0 6px 10px 4px rgba(0,0,0,.15) |
| 5 | 0 4px 4px rgba(0,0,0,.3), 0 8px 12px 6px rgba(0,0,0,.15) |

M3 の色の体系（動的な配色、トーンのパレット）は借りない。色はこのキットの「4. カラー」と、グラフは Carbon に従う。

## 写真・表紙・扉の絵: 画像生成

- 文字とロゴは画像に焼かない。画像は背景か挿絵だけにし、文字とロゴは資料側で重ねる
- 文字を置く場所（左側、上側など）を空けるように指示する
- 画風をそろえるため、採用した絵を見本として次の生成に参考画像で渡す
- 生成した絵には、色コードなどの文字が紛れ込むことがある。必ず拡大して確かめる

## 国旗: flag-icons

- 一覧と使い方: https://flagicons.lipis.dev/ 。SVG は `https://cdn.jsdelivr.net/npm/flag-icons@7.6.0/flags/4x3/{国コード}.svg`（国コードは ISO 3166-1 の 2 文字の小文字。日本 jp、台湾 tw、香港 hk、シンガポール sg、中国 cn、米国 us）
- 4:3 の版にそろえる。1 つの制作物の中で縦横比を混ぜない
- すべての国旗に 1px の薄い灰（#DDDDDD）の枠を付ける。日本やシンガポールのように白い部分がある国旗が、白い背景に溶けて形が崩れて見えるのを防ぐ
- 並べるときは同じ大きさ、同じ間隔にする

## 地図: Natural Earth の陸地データから描く

- 画像生成で地図を作ると、海岸線や島（台湾など）の形が崩れやすく、ピンの位置も合わせにくい。実際の地形データから描く
- データ: Natural Earth（https://www.naturalearthdata.com/ ）。JavaScript では npm の `world-atlas` と `d3-geo` で描ける
- 国境線は引かず、陸地を 1 色（#D4D4D4 前後）で塗る。海は薄い灰（#F2F2F2 前後）。政治的な線を描かないため
- 地球儀のように見せるときは正射図法（orthographic）にし、経緯線を薄く入れる
- ピン、引き出し線、吹き出しは画像に焼かず、資料側の図形で重ねる。後から拠点や社名を直せるようにするため
